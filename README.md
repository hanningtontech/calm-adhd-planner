# The Calm ADHD Planner

A static, responsive companion to the printable planner. Personal use: overview, today, week, month, year, brain dump, projects, home & errands, meals, money & bills, well-being, routines, work & study, goals, and notes.

Planner entries stay in this browser’s local storage. Use **Download backup** / **Restore backup** to move data between devices.

## Live site (GitHub Pages)

**https://hanningtontech.github.io/calm-adhd-planner/**

## Run locally

```bash
python3 -m http.server 3000 --directory docs
```

## GitHub Pages

Site files are in `docs/` (includes `.nojekyll`). In **Settings → Pages**: Deploy from a branch → `main` → `/docs`.
